# V8.9 opt.19 — анимация только в окне характеристик

## Что изменено

- В каталоге, корзине, инвентаре, содержимом кейсов и рулетке NFT больше не проигрываются: показывается стабильный нулевой/постерный кадр.
- Анимация запускается только в открытом окне характеристик NFT.
- При каждом новом открытии окна характеристик выполняется ровно один полный цикл, затем NFT останавливается на стабильном кадре.
- Наведение, повторный тап по изображению, прокрутка и переход между вкладками больше не перезапускают анимацию.
- Одновременно разрешён только один активный RLottie-проигрыватель. Это снижает нагрузку на CPU/GPU и память Telegram WebView.
- Добавлена защита внутри очереди и синхронизатора: даже оставшийся старый вызов не сможет запустить карточку вне модального окна.

## Версия

- API/frontend release: `8.9-opt.19`
- Python для Render: `3.12.8`

## Развёртывание

Замените файлы проекта содержимым папки/архива, отправьте изменения в GitHub и выполните **Manual Deploy → Deploy latest commit** в Render. Миграция базы данных и новые Environment-переменные не требуются.
